Roadmap to the Platinum

Five phases, built from the official descriptions: story first, then side content, then activities, then collectibles, then cleanup. The platinum lands last.

    Missable trophies — 17

    Every trophy tied to a single mission. None is missable in the cruel sense — each mission only needs to be finished when it appears — but a story mission played once and failed to count is the one way to lose a trophy, so finish each of these when it comes up.
